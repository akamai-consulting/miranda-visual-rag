# Dataset and Asset Notes

## DeepFashion

The Miranda experiment used images from the DeepFashion Category and Attribute Prediction Benchmark as a research corpus.

This repository **does not redistribute DeepFashion**. Obtain the dataset from its official source and review the terms that apply to your use:

https://mmlab.ie.cuhk.edu.hk/projects/DeepFashion.html

The repository's code should work with a user-supplied image directory, so DeepFashion is not required for basic testing.

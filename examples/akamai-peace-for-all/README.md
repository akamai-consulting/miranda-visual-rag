# Akamai × UNIQLO PEACE FOR ALL Example

Place the three author-taken T-shirt photographs used in the Miranda experiment in this directory after confirming that they are appropriate for public distribution.

Suggested filenames:

```text
akamai-peace-for-all_1.jpg
akamai-peace-for-all_2.jpg
akamai-peace-for-all_3.jpg
```

In the original experiment these three photographs were added to a corpus containing 289,219 JPGs, resulting in 289,222 indexed images.

The test query was:

```text
t-shirt with nerdy computer code
```

The query deliberately did not include `Akamai`.
